# Afghanistan Administrative Divisions Dataset
This repository contains a comprehensive dataset of Afghanistan's administrative divisions, including provinces and districts, for the years 1383 to 1389 in the Solar Hijri calendar (2004-2010 CE). The data is sourced from the Central Statistics Organization (CSO) of Afghanistan.

## Data Fields

province_code	Unique code for the province	String	"01"
province_name_eng	Province name in English	String	"Kabul"
district_code	Unique code for the district	String	"0101"
district_name_eng	District name in English	String	"Provincial center (Kabul)"

Data Quality Notes
Some district names have variations in spelling or formatting across years

The dataset includes temporary districts marked as such

Some district names include parentheses with additional information

The data reflects the administrative divisions as they were during 1383-1389 SH
